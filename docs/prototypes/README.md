# Report interface reference

`version_a_monitor.html` is the selected Version A monitoring-console prototype.
It is preserved as a visual reference only; production reports are generated by
the Python modules under `src/value_screener/`.

Production intentionally omits the prototype's demo-only JavaScript status
toggle. Abnormal reports receive the HTML `open` attribute from the backend so
that failed checks remain visible even when JavaScript is unavailable.
