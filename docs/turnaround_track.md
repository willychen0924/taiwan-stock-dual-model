# 轉機觀察獨立軌道規格

## 現況

營運動能模型把「前期 TTM 淨利不大於零、本期 TTM 淨利為正」標為轉機觀察。此分類與一般成長股的正前期淨利硬門檻互斥，因此不進入現行排名。

負基期不適合計算一般淨利成長率，轉機公司的 `ttm_net_income_growth` 必然缺值，不能直接沿用一般營運動能的100分尺度。

2026-08-03 的唯讀盤點：

| 訊號 | 有資料 | 覆蓋率 |
|---|---:|---:|
| 近3月營收年增 | 114 | 100.0% |
| 最新月營收年增 | 112 | 98.2% |
| 營收加速度 | 110 | 96.5% |
| TTM營益率變化 | 111 | 97.4% |
| 現金轉換 | 87 | 76.3% |
| TTM淨利成長 | 0 | 0.0% |
| 除淨利成長外五項全齊 | 83 | 72.8% |

盤點可由 `python3 scripts/analyze_turnaround_signals.py` 重跑。

## 建議設計

- 轉機觀察建立獨立排名，絕不與一般成長股共用總分軸。
- 「前期資料不足」維持不同分類，不得視為轉機。
- 原淨利成長10分改為轉機專用訊號；候選包括轉正後淨利率、營益率轉正幅度及連續轉正季度。
- 淨利率必須採分位數或合理封頂，並查核業外及一次性收益。
- 現金轉換缺漏要明確標示，不得默認為零後與完整資料公司直接比較。
- 在獨立軌道正式啟用前，只保留觀察分類及訊號盤點，不修改 `total_score`、`hard_pass` 或既有排名。
